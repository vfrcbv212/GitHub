Portable evaluation build for Windows x64. Extract the whole ZIP and run
VolleyVision.exe. Python, CPU libraries and detector/OCR weights are included.
Player cards without shirt numbers are supported. Optional NVIDIA preparation
downloads CUDA 12.6 packages into a separate folder and activates them only after
a successful compute check; the CPU runtime is retained.

The test suite and EXE synthetic/GUI checks run on the GitHub Windows runner
before publication. This does not establish compatibility or performance on a
specific NVIDIA computer, real volleyball accuracy, reliable person re-identification or
complete automatic match statistics. See НАЧАТЬ ЗДЕСЬ.txt and docs/FEATURES.md.

Video processing stays local. Application source and third-party notices are
included. No real match footage or full PC report is included.
