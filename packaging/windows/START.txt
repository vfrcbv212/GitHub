VolleyVision Local 0.3 — переносимая CPU-сборка для Windows x64

1. Распакуйте ВЕСЬ ZIP в обычную папку, например Документы\VolleyVision.
2. Запустите VolleyVision.exe. Python/PyCharm и установка пакетов не нужны.
   Не переносите один EXE отдельно: runtime, app и models должны лежать рядом.
3. Нажмите «Импорт видео» и выберите короткий исходный MP4/MOV (1–3 минуты).
4. «Команды и игроки»: создайте карточки, номера можно оставить пустыми.
   По умолчанию выбран режим «По внешности, без номеров».
5. При необходимости обозначьте видимые линии, сетку, судью и форму команд.
6. Выполните «Предварительный проход людей и внешности».
7. В галерее свяжите начальные изображения людей с карточками.
   После закрытия галереи программа обновит подсказки личности.
8. «Запустить анализ → отчёт». Результат в Projects\Match1\exports\automatic.

Весовые файлы детектора и OCR уже включены. «Проверить встроенные модели»
использует только локальные файлы. Интернет для обработки не нужен.
Распознавание после возвращения — пока подсказки, не проверенное надёжное ReID.
Полное распознавание волейбольных действий, блоков и исходов ещё не готово.
Для проверки интерфейса без своего видео запустите Демо.cmd: это нарисованные
данные с заранее внесёнными событиями, не результат распознавания матча.

Проекты сохраняются в Projects рядом с EXE. Если папка программы доступна
только для чтения, используется %LOCALAPPDATA%\VolleyVision\Projects.
Видеофайлы должны оставаться доступны по исходному пути; их копия не создаётся.
Сохраните всю папку проекта перед переносом программы. Звук пока не поддержан.
Первый запуск использует CPU. На длинных/4K записях обработка будет медленной.
Для совместимых видеокарт NVIDIA есть кнопка «Ускорение NVIDIA: подготовить
автоматически». Она сама скачает PyTorch/CUDA 12.6 из официального источника
в отдельную папку программы (несколько ГБ, нужно от 6 ГБ свободного места).
Ручная установка Python, CUDA Toolkit или библиотек не нужна. Не закрывайте
окно до завершения. После успешной проверки вычисления на GPU перезапустите
программу. Если загрузка/проверка не удастся, базовая CPU-сборка сохранится.
Драйвер NVIDIA программа не устанавливает и не меняет.
Подготовка CUDA и скорость на реальной NVIDIA в среде разработчика не проверены.

При ошибке запуска сохраните файл:
%LOCALAPPDATA%\VolleyVision\Logs\startup-error.txt
Передайте его разработчику вместе с описанием действия, на котором возник сбой.
Сборка не подписана цифровой подписью. Не отключайте защиту системы.

Состояние проверки: Windows-библиотеки проверяются через Wine на Linux.
Нативная Windows и NVIDIA недоступны в среде разработчика; полная совместимость
с вашим ПК и точность на реальном волейболе ещё не подтверждены.
