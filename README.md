# VolleyScope 0.1

Экспериментальная новая версия локальной видеоаналитики волейбола.

**[Скачать ZIP с EXE — 4 МБ](downloads/VolleyScope-0.1-Windows-Light.zip?raw=true)**

Распакуйте всю папку и запустите **VolleyScope.exe**. При первом запуске
Python, библиотеки и основные модели скачиваются автоматически. Нужен интернет;
подготовка может занять несколько гигабайт. Системный Python не используется.
Видео обрабатываются локально.

Исходники и инструкция по кнопкам находятся внутри ZIP. Экспорт содержит
наложения и исходный звук. Разметка по десяти кадрам необязательна.

Это предварительная сборка: распознавание всех линий/сетки/антенн/судьи и
глобальное самообучение ещё не закончены. EXE проверен по формату Windows x64;
полный запуск на Windows и NVIDIA пока не проверен. 60 FPS не подтверждены.
