# GitHub

Рабочий репозиторий для задач в Codex.

## Начальное состояние

- Основная ветка: `main`.
- Прикладной код, зависимости и тесты пока отсутствуют.
- Установка зависимостей и запуск сервера на этом этапе не требуются.

## Работа с проектом

Опишите Codex, что нужно создать или изменить. Стек, команды запуска и проверки добавляются вместе с первым приложением.

Инструкции для работы с репозиторием находятся в `AGENTS.md`.
