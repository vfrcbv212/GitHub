# Игроки без номеров — v0.3

В настройках основного окна есть три режима идентификации:

| Режим | Поведение |
|---|---|
| По внешности, без номеров | Номера полностью исключены из сопоставления; OCR не запускается |
| Внешность и номера | Внешность и необязательная подсказка номера; противоречие оставляет личность неизвестной |
| По номерам с проверкой команды | Нужен согласованный номер; сам номер не подтверждает личность |

Режим сохраняется в проекте. В «Составах» поле номера можно оставить в состоянии
«Без номера». Имя также необязательно: приложение создаёт отдельные карточки
«Игрок 1», «Игрок 2» с постоянными внутренними ID. Несколько игроков без номеров
не сливаются в одну запись. Номер можно добавить позже, сохранив ID и связи.
Одинаковые известные номера внутри команды запрещены, между командами разрешены.

Для начальной памяти в галерее нужно связать доступные изображения с карточками.
Сохраняются до трёх кадров целого человека на видимый фрагмент: одежда, силуэт
и общий внешний вид. Это не распознавание лица. Подтверждённые интервалы дают
образцы только в тех моментах, которые действительно входят в интервал.
Исправление привязки сразу меняет используемую память, старое имя не остаётся
в скрытом эталоне. Память работает внутри проекта, включая разные части записи.

После выхода и возвращения программа сравнивает новый фрагмент с этими образцами,
проверяет неоднозначность и одновременное появление одного игрока в разных местах.
Невидимая траектория и касания в промежутке не восстанавливаются как наблюдения.
Одинаковая форма, перекрытия, иной ракурс, смена одежды и длительная потеря могут
помешать сопоставлению. В таких случаях сохраняется неизвестное.

**Текущая реализация даёт подсказки личности, а не надёжное автоматическое ReID.**
Используется установленный COCO MobileNet/FPN детектора, обученный для детекции,
не специализированный для различения игроков. Признаки: 512 чисел, нормализация,
версия по SHA весов. Несовместимые версии не сравниваются. Порог cosine distance
0.25 и отрыв 0.08 — инженерные значения без проверки на реальном волейболе;
расстояние не вероятность. Новая связь остаётся identity_hypothesis, не создаёт
подтверждённую привязку и не начисляет игроку статистику. Подсказки доступны
в галерее и отчёте. Автоматический проход заканчивается без обязательных вопросов.

Смена режима использует сохранённые наблюдения и изображения, не требует заново
выполнять детекцию при том же источнике и параметрах. Для старых проектов без
полных изображений человека потребуется один новый проход (контракт наблюдений 3).
При переходе в режим с номерами OCR может дочитать сохранённые кропы формы;
нужны локальные OCR-веса. В режиме без номеров они не нужны:

```powershell
.\.venv\Scripts\python.exe -m volleyvision.cli fetch-models D:\Volley\Match1 --no-ocr
```

GUI «Подготовить модели» учитывает выбранный режим и в appearance готовит только
детектор. Дополнительные веса внешности не скачиваются. Изображения, признаки и
исходное видео остаются локально.

Проверены сохранение пустых номеров, смена режима без повторной детекции,
отмена/продолжение, исправления и конфликтующие кандидаты; реальный extractor
выполнен на CPU. Узнавание реальных игроков после выхода из кадра ещё не измерено.
