# Экспорт окон для разметки действий

После прохода детектора возьмите run_id из вывода analyze или объектов job:

```powershell
.venv\Scripts\python scripts\export_temporal.py D:\Volley\Match1 RUN_ID D:\Labels\windows.json --window-seconds 2 --stride-seconds 0.25
```

Создаются JSON с наблюдаемыми признаками и локальный windows.viewer.html со
ссылками на исходное время. Окна сохраняют PTS/time_base и SHA видео. Видео
не загружается в сервис. Метки изначально label=null, reviewed=false;
coverage_verified=false. Экспорт не превращает отсутствие событий в фон none.
Текущие интервальные роли судьи/запасных учитываются без изменения детекций.

Для пилота доступны --start/--end и --max-windows. Перезапись требует явного
--overwrite, чтобы случайно не уничтожить разметку. При отмене незавершённый
файл не подменяет прежний. match_id сохраняется для проекта; разным экспортам
того же матча нельзя давать разные ID ради разделения train/test.

Просмотрите последовательности, задайте каждому учебному окну label из
TEMPORAL.md и reviewed=true. Метка относится к фактическому среднему кадру.
Неизвестные окна оставьте непроверенными и исключите из учебного набора.
Окна none тоже требуют проверки. load_dataset откажется обучаться на
непроверенном экспорте. Честно сохраняйте data_kind=synthetic для синтетики.

Для разрешения автоматического принятия нужны отдельные реальные матчи,
полностью размеченные интервалы и эталон событий. Точность классификации
окон не заменяет TP/FP/FN событий. Команды обучения и оценки — TEMPORAL.md.
