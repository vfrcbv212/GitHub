# Начальная галерея

Одна карточка соответствует временной траектории, а не доказанной постоянной
личности. Карточка показывает все сохранённые кропы формы и точное время каждого
кадра. Двойной щелчок или кнопка перехода открывает соответствующее время исходника.
Пропавшее изображение не блокирует работу: время остаётся доступным.

Ни номер OCR, ни похожая форма, ни гипотеза второго прохода не выбирают игрока
в списке автоматически. В карточке видны голоса, причины отказа, исходные scores
и гипотезы; score не называется вероятностью правильного чтения.

Выберите команду и игрока состава, затем подтвердите интервал. Одинаковые номера
соперников относятся к разным ID. Известную команду можно сохранить с неизвестным
игроком. Судья, запасной/зритель и неизвестная роль не получают ID игрока состава.
Личность не переносится на другие фрагменты без явного выбора.

Несколько непересекающихся фрагментов можно выделить с Ctrl и привязать целиком
к одному выбранному игроку. Если фрагменты одновременно показывают разных людей,
привязка одного ID к ним отклоняется; все изменения этой операции сохраняются
атомарно. Для интервала с перепутанной личностью задайте отдельную корректировку.
Прежние записи не удаляются: новая привязка действует только на выбранном времени.
Объединение действительно дублирующих одновременно существующих траекторий
требует отдельного подтверждённого механизма и здесь не автоматизировано.

Старые противоречивые привязки подсчитываются и выделяются в списке. Они не
останавливают анализ. Любого игрока можно оставить неизвестным и закрыть галерею.
Подтверждение личности не подтверждает все будущие игровые события этого игрока.

Проверки: `QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q tests/test_gallery.py`.
Проверены несколько изображений/точное время, отсутствие OCR-автопривязки,
одинаковые номера соперников, интервальная корректировка, неизвестная личность,
атомарность непересекающегося объединения и предупреждение о конфликтах.
Это Linux/offscreen проверка интерфейса и правил хранения, не качество на реальном видео.
