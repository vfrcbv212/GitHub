# Простой режим — рабочая версия

Новая версия интерфейса находится в разработке. Опубликованный ZIP 0.3 ещё
использует прежний экран. Проверка на исходном волейбольном видео ожидается.

Основной экран: импорт видео → необязательная разметка → анализ → отчёт.
После импорта нового файла предлагается редактор выбранного кадра. Можно
выбрать другой момент, отметить только нужные элементы или пропустить разметку.
Прежние редакторы доступны через «Дополнительно».

Редактор поддерживает контур видимой площадки, центральную/трёхметровые/
лицевые/боковые линии, контур сетки с любым числом точек, две антенны, круг
мяча, рамку судьи, стороны команд и необязательные точки на людях. Точки можно
перетаскивать. Граница изображения не является доказанной линией аута; метры
из этих отметок автоматически не объявляются проверенными.

Нейросеть предлагает людей и мячи. Детектор контрастных отрезков подсвечивает
кандидатов линий без назначения: пользователь выбирает тип и подтверждает
отрезок кликом. Семантическое распознавание всех линий, антенн и полотна сетки
пока не реализовано; для них остаётся ручная разметка. Предложения не стирают
ручные точки. На другом кадре метки движущихся людей и мяча задаются заново.

Команда сохраняется в пределах непрерывной траектории: временное перемещение
нижней точки рамки при прыжке не меняет её на соперника. Ручные привязки имеют
приоритет. Пространственные голоса дают гипотезу команды, не подтверждение
личности. Новая траектория не получает прежнее имя автоматически. Рамка судьи
определяет человека на опорном кадре при однозначном совпадении; вся область
не становится постоянной маской исключения людей.

Круг мяча помогает выбрать игровой мяч среди обнаруженных объектов. Пропуски
не заполняются выдуманными наблюдениями. После потери возврат единственного
устойчивого кандидата остаётся гипотезой; при нескольких кандидатах сохраняется
неопределённость. Антенны пока служат сохранёнными ориентирами, а не автоматическим
решением о нарушении или исходе розыгрыша.

Ускорение: пакетные проходы участков изображения на CUDA, ограниченный размер
пакета с повтором после нехватки памяти, параллельное декодирование с ограниченной
очередью, пропуск заведомо внешних участков заданной области поиска мяча.
Разрешение участков и частота поиска мяча не уменьшаются. Строка состояния
показывает устройство, скорость относительно длительности видео и приблизительное
оставшееся время. В задании сохраняются времена поиска людей/мяча и второго прохода.
Скорость NVIDIA и качество на реальном матче этим не подтверждаются.
