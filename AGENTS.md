# Repository guidance

## Project state

This repository is a starting point for future coding tasks. No application stack, dependencies, build commands, or test suite has been selected yet.

## Working here

- Follow the user's task and inspect the repository before making changes.
- Choose tools and dependencies to fit the requested application; do not install a framework just to initialize the repository.
- When adding the first application, document its prerequisites, installation, development, build, and verification commands in README.md.
- Run the checks relevant to your changes. If a check cannot run, explain the concrete blocker; do not claim it passed.
- Keep credentials, tokens, private keys, and local environment values out of Git. Add a sanitized .env.example when configuration is needed.
- Preserve unrelated user changes.
