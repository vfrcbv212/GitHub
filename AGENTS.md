# Repository guidance

VolleyVision is a local Python/PySide6 volleyball 6x6 desktop application.
Read README.md and docs/FEATURES.md before changing implementation.
Preserve existing code, project schemas and annotations. Unknown fields stay
unknown; automatic acceptance never means human confirmation. Do not claim
measured volleyball accuracy without held-out annotated real footage.
Keep videos, credentials, private planning files, PC reports, model weights,
caches and environments out of Git. Public package documentation is limited
to packaging/windows/public-docs.txt and native CI verification evidence.
The user authorized public source and Windows ZIP release in this repository.
Build/test Windows releases with scripts/Build-PortableWindows.ps1.
Run relevant checks and record actual results; preserve unrelated changes.
