VolleyScope Native 0.2 — экспериментальная версия на C++.

Распакуйте весь Windows ZIP и запустите VolleyScope.exe. Python не требуется;
модели, Qt, ONNX Runtime и FFmpeg входят в архив.

Постоянный состав с запасными/либеро, OSNet для повторного узнавания, режимы
одежды и необязательных номеров, сохранение команды за человеком, окно уточнения
с отключением вопросов. Плеер: перемотка, покадровые шаги, 0,25×–10×; анализ
переносится к выбранному месту и сохраняет галерею. Экспорт — полный MP4 со звуком.

Перед публикацией выполняются нативные проверки Windows на CPU: реальные ONNX
вызовы, Unicode, покадровый кеш, экспорт и интерфейс. Проверки логики потерь,
возвращений, команд, замен и запасных мячей входят в исходники. Это не проверка
точности на конкретном матче. 30 FPS на целевой GPU пока не подтверждены.
Узнавание похожих людей и OCR номера могут оставаться неуверенными. Линии
площадки/сетки/антенн в этой версии размечаются вручную.
